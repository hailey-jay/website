# Sagitta

Hello yall!
I figure it's about time to post about my first uploaded hobby project, sagitta.
It started as a local copy of Varkor's Quiver that I edited by hand to make tweaks here and there; maybe a UI edit one day, a keybind tweak the next, wrap it in electron, etc.
Eventually it became interesting enough to put a bit more time into, and with access to LLMs, I finally had the ability to make more substantial edits.
Do note that I will never claim that Sagitta is in any way better than Quiver.
I've used Quiver for years, and the community behind it is capable of amazing things.
Put simply, Sagitta wouldn't exist if I didn't love Quiver first.

## PH

Sagitta is a graphical commutative diagram editor, forked from Varkor's Quiver. % link
The name "sagitta" is Latin for arrow.
It's a bit on the nose, but fitting nonetheless.

The keybindings work vim-*ish*, with heavy emphasis on the ish.
This is because I am an emacs user and only learned vim later.
For detailed documentation, see the repository.

Keys in Sagitta may either perform an action or drop you into a submenu.
For example, pressing the `d` key on the settings menu will toggle dark mode, but on the arrow menu, will enter the arrow body submenu.
Submenu keys toggle that menu; pressing `d` back-to-back on the arrow menu opens and then closes the body submenu.
Sliders behave like submenus, with left-right or up-down keys adjusting the level.
Alternatively, the number keys allow direct entry.


The mode is indicated by the icon on the bottom left.
Here are the modes and their keys:

SETTINGS
- VIEW
d - toggle dark mode
z - zoom slider
c - cell size (default:128px)
l - label size (default:26px)
- KEYS
q - quiver mode (default:off) % change this for next release
    When off, the canvas behaves like a spreadsheet would, and typing (besides for a few keys) drops you directly into editing the label.
    On is equivalent to having the ; mode enabled by default.
- COMMAND LIST
w - delay for menu pop-up after entering a menu (default:300ms)
