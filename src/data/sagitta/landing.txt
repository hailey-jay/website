---LEDE---

Sagitta is a keyboard-driven tikz-cd editor that produces LaTeX-ready diagrams at speed.
The syntax of tikz-cd is elegant, but it is not always the fastest to write, the easiest for complex diagrams, or the easiest to tweak afterwards.
A hand-drawn diagram is quick and accurate, but it is not reproducible and is nearly impossible to edit after creation.
Sagitta aspires to combine the benefits of both.

---COMPOSABLE_STEPS---

SPC                           | Create a vertex.
→ SPC                         | Move right and create a second vertex, with an arrow to it.
↓ SPC                         | Move down and create a third, with an arrow to it.
TAB A TAB f TAB B TAB g TAB C | <kbd>TAB</kbd> cycles through the unlabelled vertices and arrows; type a label for each.

---MODES---

<!-- The last paragraph is one sentence long, which is fine here. -->

Sagitta supports the alternative spreadsheet mode.
By default, with spreadsheet mode off, bare keys execute the commands associated with them, and <kbd>;</kbd> opens the command menu.
Label editing requires first pressing <kbd>RET</kbd>.

In spreadsheet mode, typing most keys drops directly into label editing.
Pressing <kbd>;</kbd> enables commands and shows the command menu after a short delay.
If the first character you want is otherwise bound, such as <kbd>;</kbd>, you must still first press <kbd>RET</kbd>.

The command line <kbd>:</kbd> and search <kbd>/</kbd> function the same in both modes.

---INSTALL_NOTE---

In the browser, Sagitta needs HTTPS to open and save files and folders.
Chromium opens and saves a file in place; Firefox reads a copy and saves by downloading one.
Settings and the keybindings live in the browser’s storage.
Keys the browser reserves are unavailable, so a new diagram is <code>:new</code> rather than <kbd>C-n</kbd>.

---NOTES---

Expect major changes until v1.0.0.

Sagitta is a fork of varkor’s quiver and opens quiver <code>#q=</code> links.
The <code>#q=</code> links Sagitta produces are mostly compatible with quiver, save for some constructions like checkpoint arrows and crossings.
Many thanks to varkor for giving the world quiver.

For the story of how Sagitta came to be, check out <a href="../#blog-sagitta">my blog</a>!
